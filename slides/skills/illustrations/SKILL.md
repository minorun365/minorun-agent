# 挿絵の選び方と置き方

挿絵は、あらかじめ用意したいらすとやの画像一式から選ぶ。外から画像を取ってきたり、自分で描いたりしない。

## 挿絵の探し方

- 最初に `python3 /app/bin/illust.py` を実行して、挿絵の画像一式を `/tmp/ill` に取り込む（数秒）。失敗したら挿絵なしで進める
- 一覧は `/tmp/ill/catalog.tsv`（1行目が見出し。`名前<TAB>何が描いてあるか（検索した語）`）。絵は `/tmp/ill/<名前>.png`
- そのスライドの要点を1行で言い、その場面を表す語で `grep -i <語> /tmp/ill/catalog.tsv` を引く。1語で見つからなければ言い換えて2〜3回引く
- 候補が見つかったら `read` で絵を開いて、場面が本当に合うかを見る。子どもの絵・季節ものなど、解説の場面に合わない絵は選ばない
- 合うかどうかは「その絵が、スライドの主役（話している物・人・作業）を描いているか」で決める。主役と結び付かない絵（正確さの話にカレンダー、守りの話に相談窓口）は置かない
- 技術の話は、主役を いらすとや にある物へ言い換えて引く。AI・エージェント→ロボット・人工知能、基盤・実行環境→サーバー・クラウド、設定・手順→書類・チェックリスト、費用→お金、速さ→ロケット・時計、安全→鍵・セキュリティ
- 1デッキに最低2枚は入れる。置ける候補のスライドが2枚に満たないときだけ、少なくてよい

## 置き方

- 書き方は、スライドの本文の最後に1行 `<img class="ill" src="ill/<名前>.png">`。テーマが右下に幅230pxで置く
- 置くのは、リード文と箇条書き2〜3行がある、文字だけのスライドに限る。表・図・ステップ（.steps）・流れのカード（.flow）・引用（.prompt）のスライドには置かない
- 挿絵を置くために本文を削らない。1文だけのスライドに挿絵を足して埋めない（中身の薄いスライドに見える）
- 挿絵を置くスライドの箇条書きは3行まで。右下の絵と文字が重なったら、check_deck の ng に「挿絵が本文に重なっている」と出るので、文字を減らすか絵を外す
- 同じ位置に続けて置かない。置くスライドと置かないスライドを交互にする
- 多くて5枚。前半か後半に偏らせない
- どのページにも置ける汎用の絵（OKサイン・笑顔の会社員・パソコンを使う人）で埋めない。要点に合う絵が無ければ置かない
- 表紙・中扉・締めには置かない
